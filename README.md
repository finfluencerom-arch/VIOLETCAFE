# Violet Cafebar & Lounge

Site-ul Violet Cafebar & Lounge, Lotus Center, Oradea.

- `index.html` pagina principală
- `faq.html` întrebări frecvente (SEO / GEO)
- `og-image.png` imaginea care apare când linkul e trimis pe WhatsApp / Facebook / Instagram
- `favicon.svg` iconița din tab
- `images/` pozele pentru peretele de polaroiduri (vezi `images/CITESTE.md`)

## Publicare pe GitHub Pages
1. Urcă tot conținutul acestui folder în rădăcina repo-ului.
2. Settings → Pages → Branch: `main`, folder: `/ (root)` → Save.
3. Site-ul apare la `https://<user>.github.io/<repo>/` în 1–2 minute.

## După ce ai domeniul final
În `index.html`, la `og:image`, înlocuiește `og-image.png` cu adresa completă,
de ex. `https://violetcafe.ro/og-image.png`. WhatsApp și Facebook citesc doar adrese complete.
